# ManiaRandomChartGenerator

[English](/README.md)　[中文](/introduction/README_CN.md)

## 這是什麼喵？

這是一個用 Gemini 協助製作的 osu!mania 譜面產生器喵！

它可以幫你生成各種鍵型的譜面，除了「LN」以外都可以嘗試看看喵~

## 可以做什麼喵？

- 隨機生成各種不同的鍵型的 osu!mania 譜面

## 使用步驟喵

1. 打開程式
2. 輸入想要的參數
3. 點擊「生成譜面」
4. 到 `generated_mania_maps` 資料夾裡查看生成好的譜面喵！

就這麼簡單喵？(・ω・)
